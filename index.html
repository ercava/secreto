How to Install in Minecraft

  1. Download mcsimp.zip to your computer.
  2. Extract the zip file to get the mcsimp/world directory.
  3. Press Win + R, type %appdata%\.minecraft\saves, and press Enter.
  4. Move the extracted world folder into your saves directory and rename it to Nabil Oshi SMP.
  5. Launch Minecraft Java Edition (version 1.21 or compatible), go to Singleplayer, and load your new world!
